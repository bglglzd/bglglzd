## Projects

- [3uxo](https://github.com/bglglzd/3uxo) — local-first call recorder, transcriber, and AI notes built with Rust, Tauri, and React.
- [bugkit](https://github.com/bglglzd/bugkit) — structured, context-rich bug reports for projects that use AI coding tools.
- [vps-sanity-check](https://github.com/bglglzd/vps-sanity-check) — a minimal security sanity checker for VPS hosts.
